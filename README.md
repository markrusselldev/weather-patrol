
# Weather Patrol 🌦️

## Overview

**Weather Patrol** is a full-stack application designed to handle weather data collection, processing, and presentation. This app provides a seamless integration of a React-based frontend with a Node.js/Express backend. The backend processes weather data from a TOA5 file generated by a Campbell Scientific weather station, while the frontend provides real-time updates and a user-friendly interface.

---

## Features 🚀

- **Real-Time Updates**: Using Server-Sent Events (SSE), the app pushes real-time weather data updates to the frontend.
- **Data Caching**: Weather data is cached in memory using NodeCache for fast and efficient data retrieval.
- **Data Validation**: Incoming weather data is validated against a predefined schema to ensure data integrity.
- **Multiple Themes**: The frontend offers multiple themes (dark, light, denim) to customize the user experience.
- **Security**: The app employs security best practices with Helmet for secure HTTP headers, CORS configuration, and rate limiting.

---

## Frontend 🖥️

- **Built with**: React, Vite, TailwindCSS
- **Main Files**:
  - `index.html`: The entry point for the React application.
  - `main.jsx`: The main React file that bootstraps the application.
  - **Themes**: Choose from dark, light, or denim styles by switching CSS files.

---

## Backend 🛠️

- **Built with**: Node.js, Express
- **Key Modules**:
  - **Chokidar**: Monitors the `toa5.dat` file for changes.
  - **NodeCache**: In-memory caching for fast access to weather data.
  - **Data Service**: Manages data loading, parsing, validation, and real-time updates.
  
- **API Endpoints**:
  - **GET `/api/latest`**: Retrieve the latest weather data.
  - **GET `/api/data`**: Fetch all cached weather data.
  - **GET `/api/sse`**: Establish an SSE connection for real-time updates.
  - **GET `/api/health`**: Check the server's health status.

## Installation & Setup ⚙️

1. **Clone the repository**:
    ```bash
    git clone https://github.com/markrusselldev/weather-patrol.git
    cd weather-patrol
    ```

2. **Install dependencies**:
    ```bash
    npm install
    ```

3. **Set up environment variables**:
   Create a `.env` file in the root directory with the following content:
    ```plaintext
    NODE_ENV=development
    PORT=3000
    LOG_LEVEL=debug
    ```

4. **Run the backend server**:
    ```bash
    npm start
    ```

5. **Run the frontend (in a separate terminal)**:
    ```bash
    npm run dev
    ```

---

## Usage 📊

Once the application is running, navigate to `http://localhost:3000` in your browser to interact with the frontend. The backend server will automatically monitor changes in the `toa5.dat` file and update the frontend in real-time.
