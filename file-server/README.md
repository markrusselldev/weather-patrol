# TOA5 File Server

## Description

This component is responsible for handling TOA5 weather data files generated by a Campbell Scientific weather station within the larger Weather Patrol project. The server reads, validates, and caches weather data from a `.dat` file, updated every 15 minutes, and exposes this data via RESTful API endpoints. It operates as the backend service within the unified project, focusing specifically on data processing and storage.

## Key Features

- **Input Validation**: Joi schema validation for TOA5 data.
- **Rate Limiting**: Protects against abuse by limiting API requests.
- **Security**: Includes Helmet for setting HTTP headers and CORS for managing cross-origin requests.
- **Data Processing**: Watches for updates to TOA5 files and caches the weather data for fast retrieval.
- **Server-Sent Events (SSE)**: Real-time updates for connected clients.

## Installation & Setup

The setup process has been integrated into the main project. Refer to the main [README](../README.md) for full installation and deployment instructions.

## API Endpoints

These endpoints are part of the larger project API:

- **Get Latest Weather Data**: `/api/latest`
- **Get All Weather Data**: `/api/data`
- **Server-Sent Events (SSE) Endpoint**: `/api/sse`
- **Health Check**: `/api/health`

## Configuration

Configuration is handled within the main project. The `config.json` file defines the schema for TOA5 data processing.
